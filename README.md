# Student Lesson Dashboard

An English learning dashboard for students, in one web page.

- 60 topics: 10 for each CEFR level from A1 to C2
- Each topic has a reading with audio (browser voice), a warm-up with a photo, a grammar lesson, a vocabulary lesson, 20 exercises and a writing task
- A syllabus for every level and a progress tracker

## How to open it

Open `index.html` in a browser. Keep the `img` folder next to it, because the photos load from there.

Progress and writing drafts are saved in the browser on each device. Nothing is sent to a server.
